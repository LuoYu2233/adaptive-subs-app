设置

选择生成注释用的模型，并填写你自己的 API key。key 只保存在这台电脑上，只会发给对应的服务商。

1. 注释模型

负责判断哪些词你可能不认识、写中文释义和整句翻译。按服务商和模型的用量计费，生成结果保存在本机供下次使用。

2. 语音识别：小米 MiMo（固定）

视频没有英文字幕时，用它把英语语音转成字幕，按使用的语音模型计费。有英文字幕的视频用不到。

语音模型名称
在 platform.xiaomimimo.com 注册后创建 API key。注释模型也选 MiMo 的话，两边共用这一个 key。

模型检查只读取服务商的模型列表，不生成内容；通过检查不代表实际生成能力或剩余额度。

还想先看看效果？体验自适应字幕，无需填写密钥。

保存位置：
留空的输入框表示保留已保存的 key。设置好后，打开带英文字幕（或英语语音）的 B 站或 YouTube 视频即可。
