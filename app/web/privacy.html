你的数据在哪里

适用于当前本地程序。最后更新：2026-11-24。

保存在这台电脑上

英语画像文件保存身份、专业、成绩、词汇测试以及逐词、逐义项的认识 / 不认识标记。它用于本地字幕筛选，当前生成请求不附带这些个人资料。

生成的字幕和释义、模型响应缓存、任务进度与运行日志也保存在本机。任务记录可能包含视频地址与标题；日志可能包含模型错误和字幕片段。

运行日志自动保留当前和上一份文件，每份约 2 MB，并尝试过滤已配置密钥和常见认证内容。脱敏无法识别所有个人信息，分享日志前仍应查看其内容。

API key 保存在本机配置文件中，用于本地程序向你选择的服务商发起请求；配置文件是明文，请勿分享。程序运行目录可在控制台查看。

播放器的生词本和显示设置保存在浏览器的网站数据中；插件设置保存在扩展存储中。画像备份不包含这些浏览器数据。

什么时候会发送到外部

开始字幕生成后，英文字幕及相邻上下文发送给所选注释服务商，生成中文释义与翻译。点击需要模型解释的单词时，该词及所在句子也会发送。

没有英文字幕且启用语音识别时，音频片段发送给小米 MiMo。视频播放、字幕或音频下载会连接原视频平台。服务商和视频平台分别处理这些请求。

保存并检查模型设置会向服务商请求可用模型列表，不生成字幕。无密钥互动示例使用内置原创内容，不调用模型。

本程序没有集中用户账户或云端画像同步。第三方服务如何保留和使用请求数据，请在使用前查看对应服务商的条款。

备份、恢复与删除

画像管理可以下载备份、校验并恢复备份、清除本机画像。恢复会替换当前画像；清除后只能通过你自行保存的备份恢复。

完整移除个人数据时，先退出程序，再删除用户目录中的 profile.json、tasks.sqlite3、data/、.cache/ 和 logs/。删除 config.env（源码运行时为 .env）可移除本地 key 配置；需要撤销 key 时请到服务商控制台操作。

还需在浏览器设置中清除本地播放器的网站数据，以及扩展的存储数据；自行下载的备份需单独删除。源码用户应只清理自己的用户数据，不要删除 app/data/ 内的程序词表。

本地删除不会删除已发送给第三方的数据或服务商账单；这类请求需要向相应服务商处理。
