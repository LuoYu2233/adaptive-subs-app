# Adaptive Subs：B 站插件（原型）

在 **B 站自己的播放器**上显示英文字幕，只给你可能不认识的词配中文。规则和网页版播放器一样（词汇量、宁多勿缺 / 适中 / 精简）。
没有英文字幕的视频，可以一键用**语音识别**生成英文字幕。

## 安装（Chrome 或 Edge，只需一次）

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 打开右上角的 **开发者模式**
3. 点 **加载已解压的扩展程序**，选中这个 `extension` 文件夹
4. 建议把工具栏上的拼图图标里的 Adaptive Subs 固定出来，点它可以调设置

以后改了插件文件，在扩展程序页面点它的刷新按钮，再刷新 B 站页面即可。

## 使用

1. 双击 `adaptive-subs/start.bat`，启动本地服务器（注释和语音识别都由它完成，key 只在你电脑上）
2. 在同一个浏览器里**登录 B 站**（B 站只把字幕给登录用户；语音识别不需要登录）
3. 打开一个 B 站视频，视频左上角会显示状态：
   - **有英文字幕**：马上显示，注释边看边补上，拖动进度条会优先处理你跳到的位置
   - **没有英文字幕**：显示 **「语音识别英文字幕」** 按钮。确认视频说的是英语后点它（见下文）
4. 点工具栏的插件图标，可以调整：
   - 词汇量、注释多少
   - 纯英文 / 中英对照
   - 注释在单词上方还是括号里
   - 字幕放在底部还是顶部

生成过的视频保存在 `data/extension/`，下次打开直接载入，不再花钱。

## 语音识别（没有英文字幕的视频）

点按钮后，本地服务器会：
1. 下载视频的音频：分成 1 MB 一段、8 个连接同时下载（B 站对每个连接只给开头约 3 MB 的全速，之后限速到 100–250 KB/s，分段下载可以绕开）
2. **边下载边处理**：已经下好的部分马上解码，按停顿切成一句一句（2–7 秒一段），不等整个文件下完
3. 用小米 MiMo ASR（`mimo-v2.5-asr`）识别每一段，所以每句的时间点是准的
4. 修一下断句处的大小写和标点（只改标点，不改单词），照常生成注释

**特点**：
- 优先处理你正在看的位置
- 点按钮后约 4 秒出现第一批字幕行，6 秒出现第一句识别文字，12 秒左右出现第一批注释（24 分钟视频实测）
- 音频下载：24 分钟视频约 5 秒，65 分钟约 30 秒，2 小时大约 1 分钟（海外实测，国内一般更快）
- 整集识别完的速度受 MiMo 接口频率限制（每分钟 90 次请求），大约是视频时长的 1/5；你看到哪里就先识别哪里
- 语音识别 10 分钟约 **¥0.1**，注释的费用和平时一样
- **被审核拒绝的句子由本机识别**：MiMo 的接口带内容审核，脏话、"kill"、"naked" 这类词会让整句被拒（接口返回
  "The request was rejected because it was considered high risk"）。这些句子改由程序自带的本地模型
  （Whisper base.en，int8，只用 CPU，约 76 MB）识别，每句约 1 秒，不联网、不花钱。以前生成的视频里如果还有这句提示，
  再次打开时会先隐藏，并在后台补识别，下次打开就是正确的台词

**需要的设置**：
- `.env` 里的 `MIMO_API_KEY`，见 `.env.example`
- 电脑上装有 ffmpeg

**画面里印着字幕的视频**（烧录字幕，中文、英文或中英都有）：默认显示一块**遮挡板**（磨砂模糊），盖住烧录字幕
最常出现的区域（画面高度 78%–95%、中间 80% 宽），我们的字幕显示在遮挡板上。
- **拖动遮挡板**移动它，**拖它的边缘**调大小；**双击**恢复默认；**×** 表示这个 UP 主的视频不用遮挡板
- 位置按 UP 主记住；新 UP 主沿用你最近一次调好的位置
- 插件设置里可以整体关掉遮挡板，也能把点过 × 的 UP 主「全部恢复」
- 遮挡板在 B 站控制栏下面，不会挡住进度条

**我们的字幕不会放进 B 站控制栏的区域**（鼠标移到视频底部时出现进度条的那一块），否则控制栏会盖住它，没法点也没法拖。
控制栏高度是实时量的，全屏时也一样。**拖动字幕的空白处**可以上下调整，按 UP 主记住；**双击字幕空白处**恢复自动。

**按钮需要你手动点**：没有英文字幕的视频大多是中文视频，自动识别会白花钱。如果点了之后发现说的主要是中文，服务器会自动停下来。

## 能用 / 不能用的视频

| 情况 | 结果 |
|---|---|
| UP 主上传了英文字幕 | 直接用（优先） |
| B 站自动生成的英文字幕（AI 字幕） | 直接用（可能有错字） |
| 没有英文字幕（只有中文字幕、字幕印在画面上、没登录） | 点按钮用语音识别 |
| 说中文的视频 | 语音识别会自动停止 |
| 番剧、电影频道（`/bangumi/`） | 暂不支持 |
| 超过 3 小时的视频 | 语音识别暂不支持 |

## 英语画像和熟词库

第一次用时，点插件图标里的 **「建立英语画像」**（打开 `http://127.0.0.1:8765/profile`）：
1. 选身份（高中生 / 大学生 / 研究生 / 已工作），可选填专业或行业
2. 填考过的英语考试成绩（高考、四六级、考研、雅思、托福，都可以不填）
3. 做约 3 分钟的自适应词汇测试：先每个难度抽几个词，再在你的水平分界附近多问几个，最后用例句核对词义；混有假词校正乱选

据此生成**熟词库**：成绩对应的考试词表（ECDICT 的考试标注）+ 最常见的高频词（取保守值）+ 测试里选「认识」的词。
熟词库里的单词不再注释；但**短语和熟词僻义不受熟词库影响**，认识 `upset` 也照样会解释 "upset the order"（打乱）。

**看视频时点字幕里任意单词**：暂停并弹出小卡片。有注释的词显示注释；没注释的词同时显示**词典释义**（立即出现，
来自 ECDICT，约 4.9 万词）和**这句话里的意思**（让注释模型结合整句判断，1–2 秒，同一句同一个词只花一次钱）。
卡片上还会说明为什么注释 / 不注释，可以标：
- 「我认识」：加入熟词库，不再注释
- 「我不认识」：以后总会注释（这一集没有注释的词，会用词典释义补上）
- 「恢复默认」：撤销标记，按画像判断

画像、熟词库和标记都保存在本地程序里（`profile.json`），插件、网页播放器和画像页共用同一份。标记过的词可以在画像页查看和撤销。

## 这一版还没有的

- 生词本（网页版有）
- YouTube 原网站上使用（技术上同一套做法就能支持）

## 它是怎么工作的

- `content.js`：运行在 B 站页面里，用你已登录的身份读取字幕列表，按视频的播放时间显示字幕
- `background.js`：下载字幕文件、和本地服务器通信（网页本身不允许访问 127.0.0.1，插件可以）
- `server.py` 的 `/api/ext/*` 接口：只接受带插件专用请求头的请求，别的网站没法借它花你的 API 额度
- 语音识别：服务器根据视频编号（BV 号）自己拼出 B 站地址再下载，不会去下载任意网址
- 隐私：你的 B 站登录信息不会离开浏览器，发给本地服务器的只有字幕文字和视频编号
