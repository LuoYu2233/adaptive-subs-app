# 800 题实验单词试测

使用配套 30,000 词难度表构建，两份页面可放在同一目录：

```powershell
node tools/build_cat_pilot.cjs word-difficulty-v1.json 单词试测-271.html
node tools/build_cat_pilot.cjs word-difficulty-v1.json 单词试测-800.html --expanded
```

扩展页保留原有 271 道题，增加 529 道四选一实验题。新增选项来自自行编写的四词对照组，例如四种厨具或四个不同的动作。作答时显示「用法主题」来限定词义。同一场试测最多出现每组中的一个词，避免后面的题目复用前题的整组释义。

构建器在词频名次 300 至 25,000 中，按对数名次划分十档，优先补充已有题目较少的档位。有候选词不足的档位会保留实际数量。构建结果由难度表与对照组决定。测量记录保存实际题数、版本与试题内容的 SHA-256，可用于确认多人比较时用的是哪份题库。用于字幕判词的参数仍绑定难度表指纹。

这是待真人校准的实验题库。中文选项、主题限定能否区分词义以及按水平分组后的题目表现都需要检查。源表位于 `tools/cat/bank/contrast-sets.tsv`，同一行的四个释义共同构成这组题的选项。可用同一随机种子对照 25 题的模拟误差：

```powershell
node tools/cat/benchmark.cjs word-difficulty-v1.json --expanded
```
