# 用现有视频收集单词观看反馈

1. 打开本地程序，在插件的「IRT 判词试用」导入自己的试测参数和配套难度表。
2. 打开一个已有完整注释的视频，选择「自适应」。从这个视频的扩展弹窗打开「观看记录」。
3. 填片段代号和视频领域，点击「为当前视频开始记录」，回到视频正常播放。请为同一视频沿用同一代号。
4. 在「观看记录」页停止，导出 JSON。确认已经下载后可清除本机记录，再开始下一段。浏览器一次保存一组，最多 5000 次候选词出现。

## 记录的含义

每条记录对应当次视频中一个候选单词的一处出现。记录保存在扩展本机存储，导出包含词元、句序、字符位置、实际是否显示释义、当时的模型概率、观看时间和反馈。文件用你填写的两个代号表示视频，同时保存英文字幕内容指纹，用于识别同一片段被改名重复纳入。开始和停止不会更改画像。

自然播放中，字幕须在前台，播放时间连续推进至少约 350 毫秒。一个词被主动点击也是实际看到它的证据。跳过的片段、广告、整句中文显示、其他标签页、短语、特殊义项和已经手动标记的词均不产生观看样本。未提供候选注释或未纳入难度表的普通词不在这组数据中。是否显示释义取自实际词元，包含每句和重复次数上限的影响。

一次出现最多计入一次。重播保留第一次的显示状态。打开藏着释义的候选词卡记作 lookup。已成功保存的首次显式认识或不认识标记优先于此前的查词。服务端拒绝的标记不作显式反馈。none 表示未观察到这些操作，不能当作「认识」标签。

暂停播放不会新增自然曝光。刷新、关闭或更换视频、切换试用模型会结束这组记录；已保存部分仍可导出。退出浏览器后可从扩展弹窗重新进入本页取回。导出前请自行核对是否愿意分享词元、学习时间与领域。
