# 离线单词能力试测

在开发机上准备词难度表模块生成的 word-difficulty-v1.json，然后执行下列命令。生成器需要 Node.js 22，输出文件须为新文件。

```powershell
node tools/build_cat_pilot.cjs word-difficulty-v1.json 单词能力试测.html
```

学习者可以直接用 Edge 或 Chrome 打开生成的 HTML。页面内含四选一单词题和当前难度表，全程离线。填写粗略的起始词汇量，每题选一个中文释义或“不认识”。页面关闭前可在结果页下载两个 JSON 文件。

- **判词参数**包含两种难度下分别估计的能力、区分度和难度表指纹，可直接交给离线 IRT 判词对照模块。
- **测量记录**另含逐题选择、模型、起始词汇量、期望词汇量、后验标准误和停止原因，供试测人员在本机复核。

## 测量口径

复用仓库现有四选一材料，在 30,000 词元表上可匹配 271 道单词题。原题库例句可能暗示词义，因此本轮只呈现英文单词。短语能力需要单独的题库与测量。

每次答题用 3PL 更新能力后验。“不认识”按答错计。区分度暂取 2，有效猜测率暂取 0.10。正态先验标准差为 0.8，先验均值由填写的词汇量在各自难度尺度上反推。默认 5,000 是试测起点，仍需由独立样本验证。

按照考纲先验表上当前能力处的 Fisher 信息量排序，在前五道未答题中随机抽一题。答满 12 题、标准误低于 0.16 时结束，最多 40 题。同时用另一套纯词频难度重新估计相同作答，供后续公平对照。两种估计都在试测页使用的表上计算，词汇量为该表的期望认识数。

先完成试测，再观看和盲标评估视频。收集真实学习者数据时，应另外记录测验耗时、极端水平的测量精度、题目歧义和实际观看表现，以判断是否适合接入正式测验。

## 在现有题库上复算模拟

```powershell
node tools/cat/benchmark.cjs word-difficulty-v1.json
```

固定种子为 20261125。在期望词汇量 1,500、3,000、5,000、8,000、15,000 五档各模拟 60 人，所有人均从默认 5,000 起步。每个模拟者对同一道题的潜在回答在自适应和随机两组间共享。两组都按当前 3PL 模型出答案并估计能力，比较的是选题策略。

在默认 30,000 词元表与 271 题上，同做 25 题时，自适应与随机选题的 θ 均方根误差分别为 0.236 和 0.295。300 人均答到 40 题上限，结束时平均标准误为 0.181。按当前题库安排真人试测，宜预留答满 40 题的时间。实测题目区分度、猜测率和作答耗时仍待收集。
