# 用较晚的独立视频检验观看反馈

准备同一人、同一量尺的三类本地文件：单词试测导出的完整测量记录、试测所用词难度表和多个视频的观看记录。观看记录由配套扩展的「观看记录」导出。每个视频用独立代号。先指定训练视频，再指定随后观看的留出视频。研究脚本只读取文件，输出 JSON 报告。

## Windows 图形界面

解压可选的观看校准工具，双击 `AdaptiveSubs-Calibration.exe`。依次选择单词试测导出的完整测量记录、配套词表，以及同一位学习者先前导出的观看记录。可以一次选多段。选择观看时使用的量尺，点击「生成校准报告」并保存 JSON。在扩展「IRT 判词试用」中与原始参数一同导入这份报告。程序可离线使用，已包含拟合所需的运行环境。

## 命令行

在 Windows PowerShell 的仓库目录执行：

```powershell
py -3.12 -m pip install -r tools/viewing/requirements.txt
py -3.12 tools/fit_viewing_feedback.py word-cat-record.json word-difficulty-v1.json --field b_initial --train clip01.json clip02.json --holdout clip03.json --output 行为评估.json
```

## 如何读报告

- `heldOut.anchorEventLogLoss` 和 `updatedEventLogLoss` 衡量在实际显示状态下，预测观看者下一次操作的平均负对数概率。越小越好。`deltaEventLogLoss` 为更新减去起点。两个及以上有效留出片段会给出每次去掉整个片段后差值的范围，仅供检查结果是否由单个视频主导。
- `estimate.watchingTheta` 是观看场景的总体能力。已见领域再加对应的 `domainBias`；新领域取零。全局能力与观看折扣的拆分依赖测量先验。真实生词漏注率和多注数需用另一组观看前盲标计算。
- `included` 和 `excluded` 说明有多少次出现进入似然。当前观测模型覆盖未显示释义时的查词、标为不认识或未操作，以及显示释义时的标为认识或未操作。其他组合单独计数。一次未操作只是弱证据。
- 每条记录的试用概率都要与难度表和 CAT 起点一致。文件顺序无关，训练与留出不能有相同视频代号、重复会话或重叠时间。时间衰减以最后一个训练片段的结束时间为基准。可以省略 `--holdout` 提前保存模型，再收集独立盲标；有观看留出文件时，它们只用于评分。

## 可复现实验设置

能力先验以 CAT 的 theta 与标准误确定。领域偏置先验为 N(0, 0.35²)，观看折扣取非负，先验为 N(0.15, 0.25²) 的截断分布。训练事件默认以 90 天半衰期衰减；留出评分按原始次数统计。使用 `--half-life-days` 修改衰减，使用 `--no-domain`、`--no-discount`、`--fixed-feedback` 做同集消融。

未显示释义时，未知词的「未操作、标为不认识、查词」概率共享一个总和为一的 Dirichlet 先验，参数为 (4.5, 2, 1.5)。已知词对应概率固定为 (0.975, 0.005, 0.020)。显示释义时，已知词被标为认识的概率采用 Beta(1.5, 5.5) 先验。数值是研究初值，尚待真人数据检验。拟合联合估计少量参数，并保留实际注释密度及用户反馈倾向的影响。

## 有真值的模拟对照

```powershell
py -3.12 tools/benchmark_viewing_feedback.py word-difficulty-v1.json --learners 300
```

固定种子 20261125，在 30,000 词表上模拟两类反馈活跃度、两个领域、不同的 CAT 初始误差和每句显示上限。已明确标记的词从后续可建模样本中移出。每组方法用完全相同的先前视频拟合，再预测同一批 4 个后续视频。默认让同一个人对同一个词的知识在多次出现间保持关联。加入 `--independent-encounters` 可改为每次出现独立采样。

下表是默认设定的 300 名模拟学习者各观看 80 个训练片段后的结果。能力误差以两个领域观看能力的均方根误差计；生词对数损失使用模拟器里保留的真实作答，越低越好。

| 方法 | 观看能力 RMSE | 留出生词对数损失 |
| --- | ---: | ---: |
| 只用 CAT 起点 | 0.518 | 0.479 |
| 仅用明确纠错，当成普通标注 | 0.747 | 0.583 |
| 固定反馈倾向 | 0.252 | 0.434 |
| 联合估计反馈倾向 | 0.168 | 0.421 |

独立采样设定下，联合估计的能力 RMSE 为 0.166。同样是联合估计，默认设定下低活跃组的误差为 0.206，高活跃组为 0.117。模拟使用预设的反应规律；这些数值不能说明真人漏注率已经下降。

## 用后续独立盲标检验漏注率

先在最后一段训练视频结束后冻结报告，再让同一人对没参加过训练的新视频逐句盲标。使用下面的命令直接保存 UTF-8 冻结模型，然后再开始盲标。

```powershell
py -3.12 tools/fit_viewing_feedback.py word-cat-record.json word-difficulty-v1.json --train clip01.json clip02.json --output model.json
```

旧版观看记录缺少视频或字幕指纹，可继续用于行为评分；严格的盲标留出检验需要新版采集的记录。新视频从逐句盲标页导出完整评分包。

在评分包目录保存 `clips.json`，其中代号与领域由研究者填写：

```json
{"version":1,"clips":[{"clip":"clip04","domain":"科技","packet":"片段-evaluation.json"}]}
```

```powershell
node tools/score_blind_feedback.cjs model.json word-difficulty-v1.json clips.json normal
```

输出并列显示旧规则、CAT 起点和反馈更新后的真实漏注率、每分钟多注、F2，以及可建模单词的对数损失、AUC、校准分格。报告按实际片段时长和词数汇总。阶段三只在指定量尺上评分，未见领域用零偏置。生成模型文件时会记录实际冻结时间。脚本核对视频和字幕指纹，改名或切换字幕轨仍认作同一视频。盲标须在模型文件生成后开始。请保存当时导出的原始模型文件，重新拟合会产生新的冻结时间。研究者仍需核实学习者身份及对独立视频的首次观看条件。

新版完整 CAT 测量记录包含起止时间。严格前瞻检验会确认能力测量先于训练观看。在扩展中主动导入观看校准报告后，新记录会保存实际用于显示的参数及校准截止时间，下一轮拟合继续以原始 CAT 为先验。使用特定领域偏置的记录必须与当时选择的领域一致。
