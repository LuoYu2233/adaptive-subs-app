# 实验用词难度表

本工具实现重构方案 P1 的单词尺度，用于离线对照。生成时读取项目现有的考试词表、wordfreq 的英语 large 频率数据，以及本机英语模型提供的词形规则和例外。播放器和画像均沿用各自当前版本的行为。

在仓库根目录使用 Python 3.12 生成。默认取 30,000 个词元，输出 `build/word-difficulty-v1.json`。运行阶段无需联网或模型 API。

```sh
python -m pip install wordfreq==3.1.1 spacy==3.8.18 https://github.com/explosion/spacy-models/releases/download/en_core_web_sm-3.8.0/en_core_web_sm-3.8.0-py3-none-any.whl
python tools/build_word_difficulty.py
```

- **词形合并**。本身是词典词头的形式保留独立条目，例如 `saw`。对其他形式，只有各词性规则给出唯一且词典收录的原形时，才合并其频率，例如 `went → go`。`leaves` 同时可能来自 `leaf` 和 `leave`，其频率不分摊。输入是脱离语境的词频，无法解决词性歧义。输出中的 `coverage` 给出每类处理的形式数。
- **频率对照**。`rank` 按合并后的频率从高到低排列，同频取平均名次。`b_frequency = ln(rank)`。`forms` 是贡献该词频的形式数，`letters` 是去连字符后的长度。
- **考纲实验**。`stage` 是词头最早收录的考试阶段。中考、高考、四级、六级或考研、雅思或托福、GRE 依次编码为 0 至 5。无标签记为 `null`。在全部匹配词元上计算各阶段频率对数名次的中位数，再按 `b_initial = (1 - w) × b_frequency + w × 阶段中位数` 计算实验难度。无标签时取纯频率值。默认 `w = 0.20` 是待用真人数据检验的初值，可用 `--stage-weight 0` 重建纯频率对照。
- **可复现性**。`sources` 记录依赖版本、频率表名称及考试词表的 SHA-256。`--limit` 只改变导出的条数。重新生成出错时保留上次的完整表。

难度值表示对数名次尺度上的位置。概率预测还需要同一尺度上的用户能力和区分度。短语、熟词僻义、派生词透明度、个人领域偏置和真人作答校准属于后续模块。当前没有用试用者成绩拟合权重。
