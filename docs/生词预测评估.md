# 生词预测离线评估

用同一位观看者的逐句标注，对比判词规则或注释档位。需要 Node.js 22、一份完整视频的字幕结果 JSON，以及这位观看者**观看前**的画像快照。每次评估一个人看完的一段完整视频。工具只读本地文件。

## 在插件中逐句盲标

请组织者提前准备好已有完整字幕的视频。试用者第一次打开片段前，把插件切到纯英文并关闭网站自带的译文，避免第一句的答案提前显示。打开对应的 YouTube 或 B 站视频后先暂停。字幕刚生成完时也可以直接开始。点击插件弹窗的「逐句盲标」打开独立窗口。标长视频时可展开「选择标注时间段」，输入例如 5:00 到 15:00。每段确认后先导出，再开始同一视频的下个片段。开始新标注时，程序保存观看前的有效画像。视频中的插件注释、译文和网站字幕随即隐藏；画面本身印有译文时，可先启用遮挡板。

1. 听完一句，视频会暂停。点不认识的词；标记短语时，点「选择短语」后依次点首词和末词，也可拖选原文后标记。可以点「重听本句」。
2. 点「确认并播放下句」。即使全部认识，也要确认。每次确认都会保存到扩展的本地存储；关闭后可在同一视频恢复。尚未确认的编辑不会写入草稿。切换视频或分 P 会停止此次播放控制。
3. 完成后分别导出标注和观看前画像，用下文的 `score` 命令评分。也可以导出部分进度，未看的句子保留 `null`。确认导出后，可清除这段视频在扩展中的草稿。多人使用同一浏览器时，请在换人前导出并开始新标注。

### 一轮试测怎样收集

重构方案计划邀请 8–10 位不同水平的学习者，每人看科技、日常口语、新闻各一个约 10 分钟的完整片段。用匿名代号区分学习者。先完成单词能力试测，再逐段盲标；每一段分别保留答案和当时的画像快照，避免用观看后的标记替换原快照。中途休息时可以关闭窗口，回来后继续同一份草稿。

用同一批视频和答案比较各模型。需要调整阈值时，可预先留出一组学习者或视频，只在参数确定后评估一次。项目只需要试用者主动导出的文件。判词参数可用于模型比较，完整逐题作答仅在评估测验本身时需要。

## 用文件手工标注

在仓库根目录运行以下 PowerShell 命令。把 `VIDEO_ID` 替换为已有字幕文件名，程序端口按本机实际端口填写。快照保留词汇量、现行规则的有效生熟词库，以及用户亲自标记的词。后者可用于单独评估模型对自动推断词条的判定。

```powershell
$p = Invoke-RestMethod 'http://127.0.0.1:8765/api/profile' -Headers @{'X-Adaptive-Subs'='1'}
$p | Select-Object level,known,unknown,marks | ConvertTo-Json -Depth 4 | Set-Content -Encoding utf8 viewer-before.json
node tools/evaluate_prediction.cjs prepare data/VIDEO_ID.json answers.json
```

`answers.json` 只列原句和时间，不显示预测和释义。给标注者看原片并关闭注释。逐句填写 `unknown`，包括程序可能没提取到的生词。全部认识填 `[]`，未看过的句子保留 `null`，评分器会提示补完。保留原句和时间不动。重复运行准备命令会保留已有标注。

例如在 *I went to the bank and sat on the bank.* 中，若只有第二个 *bank* 不认识，填 `[{"text":"bank","occurrence":2}]`。短语按原文整体填写，例如 `["from scratch"]`。大小写与字幕一致，序号从 1 开始，一处文字只标一次。标注工具也可写入 `{"text":"bank","s":14}` 形式，`s` 是该词在本句中从零开始的 Unicode 码点位置，评估时会与原文核对。画像和答案保存在本机，勿提交个人样本。

## 对比结果

```powershell
node tools/evaluate_prediction.cjs score data/VIDEO_ID.json answers.json viewer-before.json normal
node tools/evaluate_prediction.cjs score data/VIDEO_ID.json answers.json viewer-before.json more
```

支持 `more`、`normal`、`less`。各档调用播放器共用的判定和密度配置，按字幕顺序累计重复次数。计数单位是一次具体出现，位置和范围都与标注一致才算命中。跨档对比时使用相同的字幕、快照和答案。

| 输出字段 | 含义 |
| --- | --- |
| `missRate` | 漏注的真生词出现次数 / 全部真生词出现次数 |
| `extraPerMinute` | 多注次数 / 视频总分钟数，包含字幕间隔 |
| `f2` | 5 × 命中数 /（5 × 命中数 + 4 × 漏注数 + 多注数） |
| `missedByReason.noCandidate` | 该位置没有范围吻合的候选词 |
| `missedByReason.belowThresholdOrKnown` | 有候选，但词汇量阈值或熟词库将其过滤 |
| `missedByReason.displayLimit` | 通过判词，但受每句上限或重复次数限制 |

分母为零时相应指标返回 `null`。输出反映保存字幕在播放器中的提示选择；浏览器扩展临时补入的词和用户播放中更改的画像不参与回放。当前模型给出离散判定，概率校准指标留到模型输出概率之后。

### 从长视频选取片段

准备命令末尾可指定原视频的起止时间，单位为秒，也可用 分:秒。例如以下命令只要求标注第 5 分钟至第 15 分钟之间完整出现的字幕句。

```powershell
node tools/evaluate_prediction.cjs prepare data/VIDEO_ID.json clip-labels.json 5:00 15:00
```

片段标注附带原视频时长和选定区间，评分时仍传入完整字幕文件。跨越边界的句子从该次样本中排除。每分钟多注以选定的 10 分钟为分母，包含字幕间的空隙。播放器预先按全片累计重复上限，评分器也先处理片段前的候选，再只对片段内的标注计分。

扩展的逐句盲标在全部确认后可导出完整评分包。使用 `node tools/evaluate_prediction.cjs score-bundle 片段-evaluation.json normal` 一次读取字幕候选、标注和观看前画像。仅需发送这一份明确导出的文件。

全部确认后可直接导出完整评分包。它包含全片的英文字幕、候选词位置、此次盲标答案和仅与本片候选词有关的画像词条。中文释义、标题及与本片无关的熟词不会写入包。新建草稿记下开始和最后确认的时间，并在恢复时核对候选词指纹。候选注释变化后，仍可单独导出原有标注与画像。使用评估工具的 `score-bundle` 命令可直接读取评分包。
