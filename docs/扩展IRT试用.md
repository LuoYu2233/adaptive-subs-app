# 在视频中试用单词概率判定

准备与单词自适应试测页一起生成的词难度表，以及答完后在该页导出的判词参数。先完成盲标资料收集，再查看实验提示，以免看到答案。

1. 在已安装新版扩展的浏览器中打开扩展弹窗，点击「IRT 判词试用」。
2. 选择原始词难度表和自己的判词参数，选定「词频和考纲」或「仅词频」，点击「导入并启用」。扩展校验原始表的 SHA-256；两份文件不匹配会得到提示。
3. 在运行本地程序时打开有英文注释的 B 站或 YouTube 视频。三档注释密度按 30%、50%、70% 的不认识概率判定。点开词卡可看到此词的概率、当前阈值和显示原因。

已打开的视频会更新。手动生熟标记优先，已保存的注释仍使用原来的句内与重复上限。短语、表外词和词典临时补注沿用原规则。本地程序未能提供画像时，扩展使用原有离线行为。

判词试用设置仅存当前浏览器。可随时暂停、重新启用、移除，换人使用时重新导入相应参数。本功能不向服务器发送试测记录，也不改动已有画像。两种概率模型仍需独立学习者的观看结果校准。

已收集观看记录并完成离线校准时，也可在同一导入表单展开「使用自己的观看校准结果」，同时选择冻结的报告。程序核对难度表、能力起点、量尺与区分度。通用设置只使用观看能力和折扣；选择具体领域后，所有打开的视频暂用该偏置，词卡显示当前领域。要回到原始 CAT 起点，只需再次导入难度表和原判词参数。校准是研究功能，是否改善真人漏注率以独立盲标为准。
