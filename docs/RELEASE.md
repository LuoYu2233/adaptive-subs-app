# 0.4.0-alpha.15 本地试用版

本版用于验证新的学习体验与恢复能力。交付物为源码包，需要 Python 3.12 安装依赖；不包含 Windows 可执行程序，也没有自动部署到公开 Releases。

与 alpha.1 相比，alpha.2 增加日志容量控制与脱敏、Unicode 注释定位修复、损坏结果重试、更严格的模型响应校验、长字幕渲染优化和插件弹窗保存反馈。旧版源码包保留供回退。

alpha.3 进一步修复画像文件损坏后可能被普通标记覆盖的问题，提供先保留原始文件再重建、导入备份的恢复流程。恢复副本位于用户目录 `recovery/`，完整备份或清理时请一并处理。

alpha.4 隔离不同服务接口的模型缓存与断点，新增固定版本的本地语音模型安装校验，以及真实 CPU 识别检查工具。旧版未完成任务没有接口指纹，主动恢复时会重新生成注释和翻译，可能产生新的模型用量；已完成视频仍可直接读取。

alpha.5 增加损坏任务库的控制台恢复入口，先保留副本再重建；首份进度无法保存时阻止生成开始。后台进度每秒合并保存一次，开始、取消和结束立即保存。异常断电可能丢失最近约一秒、尚未写入的进度；模型响应缓存仍独立保存，恢复时会尽量复用。

alpha.6 改用精简任务摘要降低控制台读取开销，区分 YouTube 验证、限流和权限错误；修复音频提前断流后的无限等待，校验分段响应并限制缓冲区增长。语音识别上限为 3 小时，流式压缩音频文件上限为 384 MB，超限会明确报错；不同音频格式可能有不同文件大小。

alpha.7 增加生词本 JSON 备份与合并恢复，修复删除和撤销保存失败后的误报；播放器各页面通过 Web Locks 协调写入，显示设置不再覆盖其他页面的收藏。损坏的浏览器记录会阻止普通写入，支持先保留原文再重建，副本可下载。升级时请关闭或刷新所有旧播放器页面；旧版页面没有参与新的写入协调。不支持 Web Locks 的浏览器可读取已有记录，但会明确拒绝保存。

alpha.8 为大生词本增加搜索和分页，筛选下备份仍保留所有记录；修复快速切换插件词卡时旧查询可能改写新词卡标记对象的问题。语境查词严格校验模型返回值和缓存，传入完整有效原句，不再截掉第 400 字后的上下文。以上是数据与交互正确性改进，尚不代表真实模型的词义准确度已通过验收。

alpha.9 增加播放器失败、超时和平台限制提示及主动重试，发送嵌入播放所需的来源信息；修复导出字幕把同一单词不同意思合并计数的问题。无效导出参数不会误启动生成，损坏结果或写入失败不会覆盖已有导出文件。

alpha.10 可从已保存字幕恢复缺失或损坏的视频目录，修复损坏索引前保留副本到 `data/recovery/`；索引写入失败不会误报字幕生成失败。结果和模型缓存拒绝无效 Unicode、异常数值及过深 JSON。程序与插件检查服务身份，避免把其他本机服务认作 Adaptive Subs；启动时发现不同版本已运行会提示先退出，插件弹窗也显示版本不一致。服务识别不等同于身份认证。

alpha.11 增加用户目录的单实例保护，重复启动不会让两个服务写同一份学习数据；进程崩溃后系统自动释放锁。控制台退出操作会检查请求结果与连接状态，失败时保留操作界面，程序仍响应时不会误报退出。Linux 上真实进程生命周期及浏览器交互已验证，Windows 分支的 CI 已配置但尚未在本次环境执行。

alpha.12 对控制台最近视频使用完整结果校验，避免损坏标题影响整个控制台；未变化的字幕只复用小型元数据。启动时检查本地英语模型和词频表，失败时显示修复入口并阻止新生成，避免先请求语音识别再遇到本地处理失败。组件缺失不被视为画像损坏，已有字幕与画像备份仍可读取；修复后可从控制台重新检查。

alpha.13 改善控制台打开文件夹的操作，按系统请求文件管理器；没有桌面、缺少打开工具或系统拒绝时，显示完整路径并提供复制，复制失败也可手动复制。首次使用的数据、日志文件夹按需建立。成功提示只表示系统接受了打开请求。macOS 和 Windows 的调用分支经过隔离测试，原生桌面行为仍待相应系统验收。

alpha.14 改进源码与 Windows 制包流程：只收集 Git 提交中的源码及插件，Windows 构建使用隔离临时目录、固定语音模型与重新生成的词频表。两类 ZIP 完整写入后才发布，同版本不同内容拒绝覆盖；Windows 包增加版本、提交、依赖版本和文件校验清单。Linux 上已验证合成二进制的打包边界，尚未构建或验收 Windows EXE；本次实际交付仍是源码包。

alpha.15 改进设置页失败恢复：读取失败不会再允许无效保存，HTTP 错误和超时不会误报成功；保存与模型列表检查分别确认，检查失败可单独重试。保存响应丢失时提示重新读取，不自动重复保存。多个窗口通过编辑版本防止旧表单覆盖新设置；冲突时保留当前填写并要求重读，程序重启后旧表单也需重读。升级时刷新已打开的设置页。模型列表检查结果不代表实际生成能力或额度。

## 这一版的变化

- 不同语境的同词异义分别学习；播放器和插件共享筛选、重复提示与标记保存规则。
- 任务断点保存、重启恢复、取消、部分失败重试，以及相同字幕/音频片段的结果缓存。
- 无密钥互动体验、模型名称设置与可见性检查、完整长句处理、明确的失败提示。
- 英语画像备份、预览恢复、版本冲突保护、清除与数据说明。
- 浏览器及实际插件回归检查，支持每小时本地工程检查。

## 运行源码试用包

解压后在源码目录执行：

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app/server.py --port 8765
```

Linux/macOS 可在浏览器打开 `http://127.0.0.1:8765/app`。Linux / Python 3.12 已验证；macOS 尚未验证。
Windows 把上面的 Python 路径替换为 `.venv\Scripts\python`，也可使用 `start.bat`；本版 Windows 安装与打包产物尚未验证。

先点「先体验字幕」，不需要 key。真实视频生成需要在设置页填写自己的模型 key。模型列表检查只能确认账号可见性，不能保证实际生成能力或剩余额度。
浏览器扩展目录为 `extension/`，通过 Chrome/Edge 的扩展管理页加载已解压扩展；本版在 Playwright Chromium 中实际加载验证，Chrome/Edge 正式版本仍需独立验收。

## 本地验证与制包

```sh
python -m pip install -r requirements-browser.txt
python -m playwright install chromium
python tools/quality_check.py             # 另需 Node.js 22
python tools/browser_check.py
python packaging/source_release.py        # 仅打包干净工作树的已提交源码
python packaging/verify_source_release.py release/AdaptiveSubs-0.4.0-alpha.15-source.zip
python tools/release_smoke.py release/AdaptiveSubs-0.4.0-alpha.15-source.zip
python tools/instance_check.py           # 临时数据目录，验证重复启动、崩溃恢复和退出
python tools/runtime_check.py            # 模拟组件缺失，再加载真实本地组件验证修复
```

源码包附有逐文件 SHA-256 清单、Git 提交号和外部 `.sha256` 校验文件；相同提交可得到相同源码 ZIP。校验检测损坏或意外修改，不能替代发布者签名。
制包工具只读取 Git 提交中的允许路径，拒绝被误跟踪的 key 配置、画像、任务数据库与缓存；不从工作目录收集用户数据。

## 可选本地语音兜底

源码包不含语音模型。主动安装会从 [Systran 的公开模型仓库](https://huggingface.co/Systran/faster-whisper-base.en) 下载约 148 MB 固定版本文件，并核对逐文件 SHA-256；不需要付费 API。安装工具不会覆盖已有但不同或损坏的模型目录，可指定新目录并通过 `LOCAL_ASR_MODEL_DIR` 使用。

```sh
python tools/prepare_local_model.py --install
python tools/prepare_local_model.py                 # 再次校验，无下载
# 已有离线文件：加 --install --source /path/to/model
python tools/local_asr_check.py                    # 另需本机 eSpeak NG
```

识别时只读取完整本地模型，不补下载。真实组件检查使用三段原创合成英语和静音，保存参考文本、转写、逐词差异、耗时、音频摘要和环境信息到 `test-results/local-asr/check/`。该检查不代表真实视频、口音或噪声条件下的准确度验收，不纳入每小时离线单元测试。

## 升级与回退

1. 在画像页下载备份；等待生成完成或取消任务后退出程序。
2. 保留旧程序目录。另存一份完整用户数据目录，包括 `profile.json`、`tasks.sqlite3`、`data/`、`.cache/` 和配置文件。完整副本含明文 key 和视频记录，请自行妥善保管。
3. 把新版解压到新目录，使用原用户目录，或通过 `ASUBS_HOME` 指定独立试用目录。不要同时让两个版本写同一个用户目录。
4. 在扩展管理页重新加载新版插件，再刷新视频页面。
5. 若要回退，退出新版，恢复升级前的数据目录副本，再启动旧版及匹配的旧插件。旧版不理解新的逐义项标记，不应直接共用新版数据。

源码运行默认把用户数据放在源码根目录；Windows 打包版默认使用 `%LOCALAPPDATA%\AdaptiveSubs`。
alpha.11 增加同目录单实例保护：重复启动会使用已运行的同版本服务，换端口也不会开启第二个写入进程。崩溃退出由操作系统释放锁，无需删除文件；请把用户数据放在本机磁盘。不同版本或不支持此保护的旧程序需先退出。
画像 JSON 备份只包含学习档案；视频、任务、缓存、API key、浏览器生词本和扩展设置需另行保留。
生词本可在播放器单独导出 JSON，再从目标浏览器恢复；不同浏览器或不同本地端口不会自动同步收藏。浏览器重建前保留的原始副本用于人工检查，不能当作正常生词本备份导入。

## 已验证与未验证

已验证：Linux / Python 3.12 依赖安装、离线回归、真实 Chromium 页面交互，以及实际插件在本地模拟的视频页面上的字幕、词义卡片、标记和失败回退。云端请求使用模拟模型；本地 Whisper 另做了真实 CPU 合成语音检查，没有付费生成。

待验证：真实模型输出准确度、真实 B 站/YouTube 字幕接口与登录限制、长视频实际费用和延迟、Windows 安装与打包、自动升级及签名。
真实 YouTube 单次公共字幕获取已成功，但随后匿名访问受到平台身份验证限制，真实页面端到端检查未通过。可用 `python tools/live_youtube_check.py --video VIDEO_ID` 显式复查；该工具会联系真实平台，不包含在定时回归中。平台限制不会通过自动高频重试或读取浏览器登录信息来处理。
