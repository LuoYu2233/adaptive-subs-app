# 离线短语能力试测

运行以下命令生成单个 HTML 文件，然后在 Windows 的 Chrome 或 Edge 双击打开。答题和导出都可以离线完成。

```powershell
node tools/build_phrase_pilot.cjs 短语能力试测.html
```

每道题高亮一段真实用法形式（可能带时态），让学习者从四个中文释义中选择这句话里的意思。按 1–4 选释义，按 0 选不认识。页面给出本次答对题数、短语能力估计和后验标准误，可自行导出包含逐题作答、题库指纹的记录。

实验题库有 100 道自行编写的语境题，初始五级各 20 道，覆盖短语动词、固定表达和习语。题面与选项可在 `tools/phrases/items.tsv` 逐条审阅。初始等级尚无真人作答校准。语境可能提示答案，适合与随后独立的视频片段对照。

短语使用独立尺度：五级初始难度为 −2、−1、0、1、2，能力先验为 N(0, 1.2²)，暂用区分度 2 和有效猜测率 0.10。按信息量从前五个候选名次中抽题，同等级并列题公平抽取，每次试测不重复。至少六题且后验标准误不超过 0.45 时停止，最多八题，保留实际标准误。短语测量记录单独下载。单词能力的对数名次、期望词汇量和现有画像继续使用各自的尺度。
