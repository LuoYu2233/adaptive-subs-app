## 安装和升级

### 第一次安装

1. 到 [Releases](https://github.com/LuoYu2233/adaptive-subs-app/releases) 下载最新的 `AdaptiveSubs-Windows.zip`
2. **解压**到一个固定的文件夹（不要在压缩包里直接双击运行），比如 `D:\AdaptiveSubs`
3. 双击 `程序\AdaptiveSubs.exe`
   - Windows 提示"已保护你的电脑"：点「更多信息」→「仍要运行」
   - 杀毒软件拦截时选择允许。程序没有数字签名，所以容易被误报
4. 装浏览器插件（Chrome 或 Edge，只需一次）：
   1. 地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`）
   2. 打开右上角的「开发者模式」
   3. 点「加载已解压的扩展程序」，选择解压出来的 `浏览器插件` 文件夹
   4. 点工具栏的拼图图标，把 Adaptive Subs 固定出来，以后点它就能调设置

   程序窗口里「准备情况 → 浏览器插件」旁的「安装方法」也有这几步，还能一键打开插件文件夹。

程序需要 Windows 10 / 11 自带的 Edge WebView2 来显示窗口（Windows 11 和大多数 Windows 10 已经有了）。
没有的话，程序会改为在浏览器里打开控制台，功能一样。

### 升级到新版本

1. 关掉旧程序（窗口右下角「退出程序」）
2. 把新压缩包**解压到一个新文件夹**，旧文件夹可以删掉。直接覆盖的话，资源管理器有时还显示旧图标
3. API key、英语画像、生成过的视频都保存在 `%LOCALAPPDATA%\AdaptiveSubs`，新版直接沿用，不用重新填
4. 插件：在 `chrome://extensions` 里删掉旧的 Adaptive Subs，再「加载已解压的扩展程序」选新的 `浏览器插件` 文件夹。
   插件弹窗里的显示设置会重置；英语画像和标记过的词保存在程序里，不受影响

## 程序窗口

打开 `AdaptiveSubs.exe` 后先播放一小段入场动画（点击可以跳过），然后是控制台：

| 区域 | 内容 |
|---|---|
| 顶部大图 | 当前状态：还差 API key / 正在处理哪个视频和进度 / 一切就绪 |
| 准备情况 | 四项检查：注释模型、浏览器插件、英语画像、语音识别（可选）。没完成的项旁边有按钮直接去设置 |
| 你的词汇量 | 估计词汇量、熟词库大小，以及各词频段认识的比例 |
| 最近的视频 | 正在处理和处理过的视频，语音识别的视频有标记 |
| 运行日志 | 程序在做什么；出问题时先看这里。下方按钮打开日志文件夹、数据文件夹 |

**看视频时让程序保持运行**，可以最小化。关掉窗口就是退出程序，插件就不能再生成注释了。

## API key 和注释模型

注释（判断哪些词你可能不认识、结合上下文给出中文）由大模型完成，用的是**你自己的 API key**。
第一次打开程序时点「填写 API key」；以后在「准备情况 → 注释模型」旁点「更改」。

1. 选一个注释模型，填它的 key：

   | 模型 | 申请 key | 注释质量 | 速度（12 行一批） | 参考费用（96 行） |
   |---|---|---|---|---|
   | DeepSeek `deepseek-flash`（推荐） | [platform.deepseek.com](https://platform.deepseek.com/api_keys) | 和 GPT 接近，标得稍多 | **约 3 秒** | $0.019，非高峰时段减半 |
   | 小米 MiMo `mimo-v2.6-flash` | [platform.xiaomimimo.com](https://platform.xiaomimimo.com) | 漏掉的稍多 | 约 14 秒 | $0.006 |
   | OpenAI `gpt-6-luna` | [platform.openai.com](https://platform.openai.com/api-keys) | 好，译文最通顺 | 约 19 秒 | $0.012 |

   国内用户推荐 DeepSeek：可以直接访问、速度最快。OpenAI 需要海外网络和付款方式。
2. **语音识别（可选）**：填小米 MiMo 的 key。只有视频没有英文字幕、你点了「语音识别英文字幕」时才会用到。
   如果注释模型也选了 MiMo，同一个 key 就够了
3. 点「保存并测试」，看到"连接正常"就好了

key 保存在这台电脑的 `%LOCALAPPDATA%\AdaptiveSubs\config.env`，只会发给对应的服务商。

## 英语画像和熟词库

英语画像决定了**哪些词不用注释**。在「准备情况 → 英语画像」点「开始」，或点插件弹窗里的「建立英语画像」：

1. **身份**：高中生 / 大学生 / 研究生 / 已工作，可选填专业或行业
2. **考试成绩**：高考、四级、六级、考研、雅思、托福，考过哪个填哪个，都可以不填
3. **词汇测试**（约 3 分钟，可以跳过以后再做）：
   - 先在每个难度抽几个词，再在你的水平分界附近多问几个
   - 最后用例句核对几个词的意思，防止"眼熟但其实不会"
   - 题目里混有几个假词，用来校正乱选

据此生成**熟词库**：

- 成绩对应的考试词表（来自 ECDICT 的考试标注）
- 你这个水平几乎都认识的高频词（取保守值）
- 测试里你选「认识」的词

熟词库里的单词不再注释。但**短语和熟词僻义不受熟词库影响**：认识 upset，也照样会解释 "upset the order" 里的"打乱"。

画像页还能看到你标记过的词，可以逐个撤销；随时可以重新做测试。
画像和标记保存在程序里（`profile.json`），插件、YouTube 播放器、画像页共用同一份。

## 在 B 站看视频

1. 确认 Adaptive Subs 程序开着
2. 在装了插件的浏览器里**登录 B 站**（B 站只把字幕给登录用户；语音识别不需要登录）
3. 打开一个英语视频，播放器左上角会显示状态：
   - **有英文字幕**（UP 主上传的，或 B 站 AI 生成的）：马上显示纯英文。点左上角的「生成注释」才开始生成注释（按你的 key 计费），边看边补上；拖动进度条后会优先处理你跳到的位置
   - **没有英文字幕**：显示「语音识别英文字幕」按钮，见[语音识别](#语音识别)
4. 生成过的视频会保存下来，下次打开直接载入，不再花钱。多 P 视频每一 P 分开保存

| 视频 | 结果 |
|---|---|
| UP 主上传了英文字幕 | 直接用（优先） |
| B 站自动生成的英文字幕（AI 字幕） | 直接用（可能有错字） |
| 没有英文字幕（只有中文字幕、字幕印在画面上、没登录） | 点按钮用语音识别 |
| 说中文的视频 | 语音识别会自动停止 |
| 番剧、电影频道（`/bangumi/`） | 暂不支持 |
| 超过 3 小时的视频 | 语音识别暂不支持 |

## 在 YouTube 看视频

1. 确认 Adaptive Subs 程序开着
2. 打开一个 YouTube 视频（`youtube.com/watch?v=…`），播放器左上角会显示状态：
   - **有英文字幕**（上传者提供的，或 YouTube 自动生成的）：程序去取字幕，几秒后显示纯英文；点左上角的「生成注释」才开始生成注释
   - **没有英文字幕**：显示「语音识别英文字幕」按钮，见[语音识别](#语音识别)
3. 播放广告时不显示我们的字幕，广告结束后自动恢复

和 B 站不一样的地方：

- **字幕由程序去取**：YouTube 的字幕文件只给它自己的播放器，插件拿不到，所以交给程序（yt-dlp）去取。
  程序没开时，YouTube 上连纯英文字幕也显示不了
- **程序要能连上 YouTube**：程序走系统代理。用代理软件的话，打开它的「系统代理」；连不上时插件会提示，可以点「重试」
- **和 YouTube 播放器共用结果**：在插件里看过的视频，[YouTube 播放器](#youtube-播放器实验)里也是已生成的，反过来也一样

| 视频 | 结果 |
|---|---|
| 上传者提供了英文字幕 | 直接用（优先） |
| YouTube 自动生成的英文字幕 | 直接用（可能有错字） |
| 没有英文字幕 | 点按钮用语音识别 |
| Shorts 短视频、正在直播的视频 | 暂不支持 |
| 超过 3 小时的视频 | 语音识别暂不支持 |

## 点单词

点字幕里任意一个单词，视频暂停并弹出一张卡片：

- **有注释的词**：显示这句话里的意思
- **没注释的词**：立即显示**词典释义**（ECDICT，约 4.9 万词），再用 1–2 秒给出**这句话里的意思**（同一句同一个词只问一次模型）
- 卡片会说明为什么注释 / 没注释（比如"在你的熟词库里"）

卡片上的按钮：

| 按钮 | 作用 |
|---|---|
| 我认识 | 加入熟词库，以后不再注释 |
| 我不认识 | 以后总会注释；这一集里没有注释的地方，用词典释义补上 |
| 恢复默认 | 撤销标记，按英语画像判断 |

## 快捷键

在 B 站或 YouTube 看视频、屏幕上有我们的字幕时可以用：

| 键 | 作用 |
|---|---|
| 按住 **Z** | 看这一句的中文翻译，松开就消失。轻点一下：一直显示到下一句开始，再点一下收起。两句之间的空白处按，看的是刚说完的那句 |
| **B** | 切换字幕：自适应 → 纯英文 → 中英对照（和插件弹窗里的「字幕」是同一个设置） |
| **P** | 遮挡板 开 / 关，按 UP 主 / 频道记住（没有我们的字幕时也能用） |

- 选的都是 B 站和 YouTube 自己没有用到的键，不会误触点赞、投币之类
- 在评论框、搜索框、弹幕输入框里打字时不会触发；中文输入法开着也能用
- 视频刚开始生成注释时，有些句子的中文翻译还没出来，按 Z 会提示"还没生成好"

## 遮挡板和字幕位置

很多视频的字幕直接印在画面里（中文、英文或中英都有），会和我们的字幕叠在一起。

**遮挡板**：一块磨砂板，盖住烧录字幕最常出现的区域（画面高度 78%–95%、中间 80% 宽），我们的字幕显示在板上。
默认不显示；看视频时按 **P** 打开（或在插件弹窗「这个 UP 主 / 这个频道」那一行选「显示」），再按 P 关掉。

- **拖动**遮挡板移动它，**拖边缘**调大小，**双击**恢复默认位置
- 点 **×** 或按 **P**：这个 UP 主 / 频道的视频不再显示遮挡板
- 位置按 UP 主 / 频道记住；新的 UP 主沿用你最近一次调好的位置
- 遮挡板在播放器控制栏下面，不会挡住进度条

**字幕位置**：

- 我们的字幕不会进入播放器控制栏的区域（鼠标移到视频底部时出现进度条的那一块），否则会被盖住、点不到。控制栏高度是实时量的，全屏也一样
- **拖动字幕的空白处**可以上下调整，按 UP 主 / 频道记住；**双击字幕空白处**恢复自动

## 语音识别

没有英文字幕的视频，点播放器左上角的「语音识别英文字幕」。需要在设置里填小米 MiMo 的 key。

按钮需要手动点：没有英文字幕的视频大多是中文视频，自动识别会白花钱。如果识别出来主要是中文，程序会自动停下。

**过程**：

1. 下载视频的音频：分成 1 MB 一段、8 个连接同时下载。B 站对每个连接只给开头约 3 MB 的全速，之后限速到 100–250 KB/s，分段下载可以绕开；YouTube 的音频几秒就能下完
2. **边下载边识别**：下好的部分马上解码、按停顿切成一句一句，不等整个文件下完；优先处理你正在看的位置
3. 每一句用小米 MiMo ASR（`mimo-v2.5-asr`）识别，所以每句的时间点是准的
4. 修一下断句处的大小写和标点（只改标点，不改单词），然后照常生成注释

**速度**（实测）：

- 点按钮后约 4 秒出现第一批字幕，十几秒出现第一批注释
- 音频下载：24 分钟的视频约 5 秒，2 小时约 1 分钟
- 整集识别完大约是视频时长的 1/5（受 MiMo 接口频率限制），你看到哪里就先识别哪里

**被拒绝的句子**：MiMo 的接口带内容审核，脏话、"kill" 这类词会让整句被拒。这些句子由程序自带的本地模型补上
（Whisper base.en，int8，约 76 MB，只用 CPU），每句约 1 秒，不联网、不花钱；很旧的电脑上每句约 2–3 秒。
欢呼、音乐处出现的 `<chinese>`、`[Music]` 这类标签会被去掉。以前生成的视频如果有这些问题，再次打开时会自动修复。

## YouTube 播放器（实验）

程序运行时，在浏览器打开 <http://127.0.0.1:8765/>（端口被占用时会顺延到 8766、8767……，以运行日志里的地址为准），
在顶部粘贴 YouTube 链接回车：几秒内拿到英文字幕开始播放，注释边看边生成，处理完自动保存。

现在插件可以直接在 youtube.com 上用（见[在 YouTube 看视频](#在-youtube-看视频)）。这个播放器适合没装插件的浏览器，
或者想用下面这些功能的时候；两边生成过的视频是共用的。

播放器还有生词本（可导出 CSV 给 Anki）、本集预习、字幕全文、精听（R 重听本句，← → 上一句 / 下一句）。

不装程序也能看效果：[在线演示](https://luoyu2233.github.io/adaptive-subs/) 里有几个已经处理好的视频。

## 隐私和数据保存在哪里

- 程序只在本机 `127.0.0.1` 运行，别的电脑和网站访问不到；只接受插件和程序自己的请求，别的网站没法借它花你的额度
- 你的 B 站、YouTube 登录信息不会离开浏览器。B 站：发给程序的只有字幕文字和视频编号；YouTube：只有视频编号，字幕由程序自己去取
- 语音识别时，程序根据视频编号（BV 号或 YouTube 视频 ID）自己拼出视频地址再下载，不会去下载任意网址
- 发给模型服务商的只有字幕文字（和语音识别时的音频片段）

所有数据都在 `%LOCALAPPDATA%\AdaptiveSubs`（在程序窗口点「数据文件夹」可以直接打开）：

| 文件 / 文件夹 | 内容 |
|---|---|
| `config.env` | 注释模型的选择和 API key |
| `profile.json` | 英语画像、熟词库和标记过的词 |
| `data\extension\` | B 站视频的字幕和注释，以及 YouTube 视频语音识别的结果 |
| `data\` | YouTube 视频的字幕和注释（插件和 YouTube 播放器共用） |
| `.cache\` | 模型返回结果的缓存（同样的请求不重复花钱）和用量记录 `usage.jsonl` |
| `logs\` | 运行日志 |
| `webview\` | 程序窗口的浏览器缓存 |

想彻底删除：退出程序，删掉解压的文件夹和 `%LOCALAPPDATA%\AdaptiveSubs`，再在 `chrome://extensions` 里移除插件。

## 常见问题

**插件提示"程序没开"**
确认 Adaptive Subs 程序开着（可以最小化），然后刷新视频页面。程序没开时，B 站上只能显示纯英文字幕，YouTube 上什么都显示不了。

**YouTube 提示"连不上 YouTube"**
YouTube 的字幕由程序去取，程序要能连上 YouTube。用代理软件的话，打开它的「系统代理」（或者叫「设置为系统代理」），再点提示里的「重试」。

**提示 key 无效 / 注释一直不出来**
在程序窗口「准备情况 → 注释模型」点「更改」，重新填写后「保存并测试」。再看看运行日志里有没有报错，比如余额不足。

**8765 端口被占用**
程序会自动换一个端口，插件会自己找到，不用管。

**字幕和画面里原有的字幕重叠了**
插件弹窗里打开「遮挡板」，在视频上把它拖到原字幕的位置并调好大小；或者把「字幕位置」改成顶部。

**有些词我认识却被注释了 / 不认识却没注释**
点那个词，选「我认识」或「我不认识」。差得多的话，在英语画像页重新做一次词汇测试，或者在插件里调「注释多少」。

**没有「语音识别英文字幕」按钮**
这个视频已经有英文字幕（会直接显示），或者是番剧 / 电影频道（暂不支持）。

**提示"这个视频说的主要是中文"**
语音识别只支持英语视频。

**程序打不开 / 闪退**
看 `%LOCALAPPDATA%\AdaptiveSubs\logs\adaptive-subs.log`，带上最后几十行到 [Issues](https://github.com/LuoYu2233/adaptive-subs-app/issues) 反馈。
