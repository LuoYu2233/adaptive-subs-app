Adaptive Subs 设置

选择生成注释用的模型，并填写你自己的 API key。key 只保存在这台电脑上，只会发给对应的服务商。

1. 注释模型

负责判断哪些词你可能不认识、写中文释义和整句翻译。三家都按用量计费，一集 10 分钟的视频大约几毛钱。

2. 语音识别：小米 MiMo（固定）

B 站视频没有英文字幕时，用它把英语语音转成字幕（10 分钟约 ¥0.1）。有英文字幕的视频用不到。

在 platform.xiaomimimo.com 注册后创建 API key。注释模型也选 MiMo 的话，两边共用这一个 key。

保存位置：
留空的输入框表示保留已保存的 key。设置好后，打开带英文字幕（或英语语音）的 B 站视频即可。
